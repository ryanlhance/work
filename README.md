# work

An interactive portfolio: working prototypes, tools and maps, as a gallery of
cards that link straight to the live thing.

https://ryanlhance.github.io/work/ — `noindex` + `robots.txt`, link-only.

## Structure

- `data.js` — every card and speaking topic. The only file to edit to add work.
- `index.html` / `styles.css` / `app.js` — content-free renderer.
- `shots/` — card screenshots, regenerated by `shoot.py`.
- `workshop/` — the Weekly Performance Brief walkthrough (its own page).

## Adding a card

Add an entry to `data.js`. `status: "live"` makes it clickable; `status: "soon"`
renders it dimmed. Then add the site to `SITES` in `shoot.py` and run it.

## Screenshots

```
python3 -m pip install --user playwright
python3 -m playwright install chromium
python3 shoot.py              # all cards
python3 shoot.py fitmap       # just one
```

Captured at 1440x900 (16:10, the card aspect ratio) at 2x.

## The workshop page

`workshop/build.py` regenerates `workshop/data.js` from the real files in
`workshop/inputs/`, so no number on the page is ever retyped. The brief's page
images in `workshop/brief/` are rendered from the PDF with PyMuPDF.

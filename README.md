# work

Ryan Hance's AI Builds — an interactive portfolio. Every card opens a page that
runs the real thing inside the site, so there is always a way back.

https://ryanlhance.github.io/work/ — `noindex` + `robots.txt`, link-only.

## Structure

- `data.js` — cards and the Ask Me About topics. The only file to edit to add work.
- `index.html` / `styles.css` / `app.js` — content-free renderer. Cards group into
  sections by their `tag`, so reordering `data.js` regroups the page.
- `<slug>/` — a viewer per piece, generated by `make_viewers.py`.
- `pieces/` — self-contained builds that live here rather than on their own site.
- `workshop/` — the TIFF practical interview case study.
- `shots/` — card screenshots, regenerated by `shoot.py`.

## Viewers

`make_viewers.py` holds one row per piece: slug, title, category, source, and any
CSS to inject. Full-screen pieces frame their live site; Feels Like and Record
Collection render inside a phone.

Everything sits on one github.io host, so the shell and the framed piece share an
origin. That is what lets the shell hand an app real safe-area insets, cancel
native image drags a phone would never start, and hide the league's dues link in
the portfolio's copy without touching the real hub. The dev server proxies the
pieces that need it so the preview behaves the same.

## Link preview

`make_share_image.py` renders `share.png` at 1200x630 from the site's own tokens
and screenshots. Re-run it if the title or the featured projects change.

`robots.txt` allows the preview bots and disallows everyone else. A blanket
disallow would stop those bots fetching the page at all, so a shared link would
unfurl as a bare URL. What actually keeps the site out of search is the
`noindex` tag on every page.

## Files authored elsewhere

Five files here are exported from other projects: the two DCHC builds, the
career map, the dashboard, and the skill. Editing them in place means the next export silently
undoes the edit, so the edits live in `import_pieces.py` instead. After any
re-export:

```
python3 import_pieces.py
python3 shoot.py --local draftroom frontoffice dashboard careerarch
```

It is idempotent, and it fails loudly if an export's markup changed enough that
an edit no longer applies, rather than shipping it half-done. The viewer also
re-applies the DCHC title expansion at load time if it finds it missing, so a
file dropped in without running the script still renders correctly.

## Screenshots

```
python3 -m pip install --user playwright
python3 -m playwright install chromium
python3 shoot.py              # all cards
python3 shoot.py fitmap       # just one
python3 shoot.py --local ...  # capture this site from the dev server, pre-deploy
```

Captured at 1440x900, or 375x812 for the phone cards. After recapturing, bump
`shotsVersion` in `data.js` or browsers keep serving the old image.

## The workshop page

`workshop/build.py` regenerates `workshop/data.js` from the real files in
`workshop/inputs/`, so no number on the page is ever retyped.
